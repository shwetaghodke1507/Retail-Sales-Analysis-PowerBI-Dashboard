### 📊 Key Business Insights
- **Total Sales:** 11.31M | **Total Profit:** 1.30M (Margin: 0.11)
- **Total Orders:** 750 | **Total Customers:** 368

### 🔍 Dashboard Analysis
- **Region:** West region dominates with 51.98% sales (5.88M)
- **Category:** Electronics is top performer - 59.45% (7.49M sales, 0.81M profit)
- **Trend:** Monthly sales trend Jan-Apr 2025 tracked
- **State:** Maharashtra leads in sales
- **Filters:** Interactive date slicer (Jan-Dec 2025)
